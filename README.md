# Linux Command Line Mastery

## Project Overview

This project demonstrates practical Linux command-line skills, including file management, directory navigation, system administration, networking, pipes, redirection, and Bash scripting.

## Command List

- `pwd` — Display the current directory
- `ls` — List files and directories
- `cd` — Navigate between directories
- `mkdir` — Create directories
- `touch` — Create files
- `cp` — Copy files and directories
- `mv` — Move or rename files and directories
- `rm` — Remove files and directories
- `cat` — Display file contents
- `find` — Search for files and directories
- `grep` — Search for text
- `top` — Monitor running processes
- `ping` — Test network connectivity
- `|` — Connect commands with a pipe
- `>` and `>>` — Redirect command output
