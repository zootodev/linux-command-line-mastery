# Linux Command Line Mastery

## Project Overview

Linux Command Line Mastery is a practical project designed to develop and demonstrate fundamental Linux command-line skills.

The project covers file management, directory navigation, system monitoring, networking, pipes, input/output redirection and Bash scripting.

It involves executing Linux commands, documenting their outputs, identifying and resolving errors, and developing practical shell scripts.

## Project Objectives

- Understand basic Linux command-line operations.
- Learn how to manage files and directories.
- Navigate the Linux filesystem using absolute and relative paths.
- Monitor system resources and manage file permissions.
- Understand basic networking commands.
- Process command outputs using pipes and redirection.
- Develop reusable Bash scripts for automation.

## Project Tasks

### Task 1: File Management

Practised creating, copying, moving, renaming and deleting files and directories. Also explored file viewing and searching using Linux commands.

**Status:** Completed.

### Task 2: Directory Navigation

Practised navigating the Linux filesystem using absolute and relative paths, creating nested directories and exploring standard Linux directories such as `/etc`, `/var` and `/tmp`.

The task included checking the current working directory, navigating to the home directory, creating nested project directories and verifying the resulting directory structure using directory listing and search commands.

**Status:** Completed.

### Task 3: System Monitoring and Administration

Practised monitoring running processes and system resources using `ps`, `top`, `uptime`, `free` and `df`. Also explored user and group identification, file permission management with `chmod`, file ownership management with `chown`, and administrative privileges using `sudo`.

**Status:** Completed.

### Task 4: Networking Basics

Practised network connectivity testing and inspected network configuration and listening TCP/UDP sockets using `hostname`, `ip addr`, `ping` and `ss`.

**Status:** Completed.

### Task 5: Pipes and Redirection

Practised redirecting standard output and error messages using `>`, `>>` and `2>`. Also chained commands using pipes (`|`) with `grep`, `awk`, `sort` and `uniq` to filter and process text data.

**Status:** Completed.

### Task 6: Shell Scripting

Created and tested a reusable Bash script named `directory_logger.sh` using variables, an array, conditional statements and a `for` loop. The script automates directory creation, checks whether directories already exist, and records its activities and timestamps in a log file. Validated the script, made it executable and tested repeated execution.

**Status:** Completed.
